# Конспект: основы нейросетей, архитектура и обучение

## 1. Общая модель нейросети

Нейросеть — параметризованная математическая функция:

\\[ \boxed{\hat y=f\_\theta(x)} \\]

Где:

- \\(x\\) — входные данные.
- \\(\theta\\) — набор обучаемых параметров (весов и смещений).
- \\(\hat y\\) — предсказание нейросети.

Архитектура определяет набор вычислительных операций и связи между ними. Обучение изменяет параметры этих операций, чтобы приблизить предсказания к требуемым результатам.

## 2. Пример: нейросеть сравнивает два числа

Задача: определить, больше ли первое число второго.

Входные данные:

\\[ x=(a,b) \\]

Правильный ответ:

\\[ y= \begin{cases} 1,&a>b\\\ 0,&a\le b \end{cases} \\]

### Архитектура: один искусственный нейрон

a

Первое число

b

Второе число

× w₁

× w₂

z = w₁a + w₂b + c

Линейное преобразование

p = σ(z)

Сигмоида: значение от 0 до 1

Переменные:

| Обозначение   | Назначение                              |
| ------------- | --------------------------------------- |
| \\(a,b\\)     | Входные числа, которые сравниваем       |
| \\(w_1,w_2\\) | Обучаемые веса                          |
| \\(c\\)       | Обучаемое смещение (bias)               |
| \\(z\\)       | Результат линейного преобразования      |
| \\(p\\)       | Оценка вероятности ответа 1             |
| \\(y\\)       | Известный правильный ответ при обучении |

### Вычисление предсказания

Сначала:

\\[ z=w_1a+w_2b+c \\]

Затем функция активации — сигмоида:

\\[ \boxed{\sigma(z)=\frac{1}{1+e^{-z}}} \\]

Она преобразует произвольное действительное число в интервал \\((0,1)\\).

При классификации:

\\[ \hat y= \begin{cases} 1,&p>0.5\\\ 0,&p\le0.5 \end{cases} \\]

Здесь \\(\hat y\\) — вычисленный ответ модели, а \\(y\\) — правильный ответ из обучающего примера.

## 3. Функция ошибки

Обучение требует измерять, насколько предсказание отличается от правильного ответа.

Мы выбрали Binary Cross-Entropy (BCE).

Поскольку \\(p\\) интерпретируется как вероятность ответа 1:

\\[ P(Y=1)=p \\]

\\[ P(Y=0)=1-p \\]

Эти два случая объединяются:

\\[ P(Y=y\mid p)=p^y(1-p)^{1-y} \\]

Мы хотим максимизировать вероятность правильного ответа. Поэтому минимизируем её отрицательный логарифм:

\\[ L=-\ln P(Y=y\mid p) \\]

Получаем:

\\[ \boxed{ L=-y\ln p-(1-y)\ln(1-p) } \\]

Примеры ошибки, когда правильный ответ \\(y=1\\):

| Предсказание \\(p\\) | Ошибка \\(L\\) |
| -------------------- | -------------- |
| 0.01                 | 4.605          |
| 0.5                  | 0.693          |
| 0.9                  | 0.105          |
| 0.99                 | 0.010          |

Чем большую вероятность модель приписывает правильному ответу, тем меньше ошибка.

BCE — не единственная возможная функция потерь, но она естественно выводится из модели Бернулли.

## 4. Обучение: градиентный спуск

Обучаемые параметры:

\\[ \theta=(w_1,w_2,c) \\]

Нужно изменять их так, чтобы уменьшалась ошибка \\(L\\).

Для этого используется градиентный спуск:

\\[ \boxed{ \theta\_{\text{new}}= \theta-\eta\nabla\_\theta L } \\]

Где:

- \\(\eta\\) — скорость обучения (learning rate).
- \\(\nabla\_\theta L\\) — градиент ошибки по параметрам.

Градиент содержит производные, показывающие, как небольшое изменение каждого параметра влияет на ошибку.

### Вывод производных

Наша цепочка:

\\[ \theta\longrightarrow z\longrightarrow p\longrightarrow L \\]

Используем правило производной сложной функции:

\\[ \frac{\partial L}{\partial z} = \frac{\partial L}{\partial p} \frac{\partial p}{\partial z} \\]

Для BCE:

\\[ \frac{\partial L}{\partial p} =-\frac{y}{p}+\frac{1-y}{1-p} \\]

Для сигмоиды:

\\[ \frac{\partial p}{\partial z}=p(1-p) \\]

Перемножаем и сокращаем:

\\[ \boxed{ \frac{\partial L}{\partial z}=p-y } \\]

Поскольку:

\\[ z=w_1a+w_2b+c \\]

получаем:

\\[ \boxed{ \begin{aligned} \frac{\partial L}{\partial w_1}&=(p-y)a\\\ \frac{\partial L}{\partial w_2}&=(p-y)b\\\ \frac{\partial L}{\partial c}&=p-y \end{aligned} } \\]

Это формулы, по которым можно вычислять обновление всех трёх параметров.

## 5. Числовой пример одного шага обучения

Дано:

\\[ a=7,\quad b=3,\quad y=1 \\]

Начальные параметры:

\\[ w_1=w_2=c=0 \\]

Скорость обучения:

\\[ \eta=0.1 \\]

### Шаг 1. Предсказание

\\[ z=0 \\]

\\[ p=\sigma(0)=0.5 \\]

### Шаг 2. Ошибка

\\[ L=-\ln(0.5)\approx0.693 \\]

### Шаг 3. Градиент

\\[ p-y=-0.5 \\]

\\[ \nabla\_\theta L= \begin{pmatrix} -3.5\\\ -1.5\\\ -0.5 \end{pmatrix} \\]

### Шаг 4. Обновление параметров

\\[ \theta\_{\text{new}} = \begin{pmatrix}0\\\0\\\0\end{pmatrix} -0.1 \begin{pmatrix}-3.5\\\\-1.5\\\\-0.5\end{pmatrix} \\]

\\[ \boxed{ w_1=0.35,\quad w_2=0.15,\quad c=0.05 } \\]

### Шаг 5. Повторное предсказание

\\[ z=0.35\cdot7+0.15\cdot3+0.05=2.95 \\]

\\[ p=\sigma(2.95)\approx0.950 \\]

Предсказанная вероятность правильного ответа выросла с 0.5 до 0.95.

Но это только один обучающий пример. Новые веса пока плохо обобщают правило сравнения. Например, для `(2, 5)` эта модель ошибочно выдаст \\(p\approx0.818\\).

Чтобы научиться сравнивать произвольные пары чисел, модель должна обучаться на множестве разнообразных примеров.

## 6. Почему обучение работает

При обучении на множестве пар чисел веса могут приблизиться к:

\\[ w_1=k,\quad w_2=-k,\quad c=0 \\]

Для некоторого \\(k>0\\):

\\[ z=k(a-b) \\]

Тогда:

\\[ \begin{aligned} a>b&\Rightarrow z>0\Rightarrow p>0.5\\\ a\<b&\Rightarrow z<0\Rightarrow p<0.5 \end{aligned} \\]

То есть нейросеть может научиться реализовывать сравнение чисел, не получая непосредственно алгоритм сравнения.

Она подбирает параметры по примерам. При этом способность найти правильное решение зависит от архитектуры, обучающих данных, функции ошибки и процесса оптимизации.

## 7. Ограничения архитектуры

Один искусственный нейрон вычисляет:

\\[ p=\sigma(w_1a+w_2b+c) \\]

При классификации порогом 0.5 граница между ответами 0 и 1 определяется уравнением:

\\[ w_1a+w_2b+c=0 \\]

На плоскости это прямая.

Иллюстрация линейной границы: по одну сторону ответ 1, по другую — 0.

Для сравнения двух чисел такой границы достаточно.

Но для некоторых задач, например XOR, одной прямой недостаточно. Это уже ограничение архитектуры, а не ошибка обучения. Для подобных задач можно добавить скрытый слой и нелинейные преобразования.

## 8. Что ещё разобрали: Attention

Attention — механизм обращения к информации по содержимому.

Его компоненты:

| Обозначение      | Назначение                                            |
| ---------------- | ----------------------------------------------------- |
| Query \\(q\\)    | Запрос                                                |
| Keys \\(k_i\\)   | Представления элементов, с которыми сравниваем запрос |
| Values \\(v_i\\) | Информация, которую элементы могут передать           |
| \\(s_i\\)        | Оценка соответствия запросу                           |
| \\(a_i\\)        | Вес информации от элемента                            |

Сначала вычисляется соответствие:

\\[ s_i=q\cdot k_i \\]

Затем нормализуются оценки:

\\[ a_i=\frac{e^{s_i}}{\sum_j e^{s_j}} \\]

И получается результат:

\\[ \boxed{y=\sum_i a_iv_i} \\]

В Transformer используется масштабированная версия, обычно с \\(1/\sqrt{d_k}\\), чтобы контролировать величину оценок.

Мы вывели назначение этого механизма на задаче поиска значения по ключу. Однако в том примере ключи были заданы вручную: мы разобрали работу Attention, но ещё не обучение его параметров.

## 10. Что изучать дальше

Ближайшая практическая задача — самостоятельно реализовать и обучить наш нейрон без PyTorch:

1. Вычисление \\(z\\) и \\(p\\).
2. Вычисление BCE.
3. Ручной расчёт градиента.
4. Обновление параметров.
5. Обучение на множестве случайных пар чисел.
6. Проверка на новых данных.

После этого логичный следующий уровень — несколько нейронов и скрытый слой, чтобы на конкретной задаче выяснить, зачем усложнять архитектуру.

Главная формула всего разобранного:

\\[ \boxed{ \underbrace{x\xrightarrow{f\_\theta}\hat y}\_{\text{Предсказание}} \quad\longrightarrow\quad \underbrace{L(\hat y,y)}\_{\text{Ошибка}} \quad\longrightarrow\quad \underbrace{\nabla\_\theta L}\_{\text{Градиент}} \quad\longrightarrow\quad \underbrace{\theta'=\theta-\eta\nabla\_\theta L}\_{\text{Обучение}} } \\]

И главное различие: архитектура задаёт пространство возможных вычислений, а обучение подбирает внутри него параметры.
